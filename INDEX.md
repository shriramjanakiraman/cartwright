## Our skills (`core/`)

| Skill | Status | Applies to | Description |
|---|---|---|---|
| `client-setup` | active | any | Connect a client project to the shared SFCC skills and that client's own project skills, so every developer who opens it gets both automatically. Use when the session-start notice says this project isn't set up, or when a developer says \"set up this project's skills\", \"connect this repo to the client skills\", \"which client skills do we have\", \"I can't see the project skills\" or \"onboard me to this client project\". Finds the client's existing project skills from any spelling or abbreviation of its name, checks access, adds the small project kit after asking, or guides creating project skills for a new client. |
| `skill-intake` | active | any | Turn an idea, a workflow you just did, notes, or an existing project skill into a properly classified, scrubbed and submitted skill for the shared agent-skills library, with the agent doing the work and the developer answering a few questions. Use when a developer says things like \"make this a skill\", \"save this as a skill\", \"I want to add a skill\", \"contribute this to the skills repo\", \"promote this project skill\", or \"improve the X skill\". Not for using an existing skill. |
